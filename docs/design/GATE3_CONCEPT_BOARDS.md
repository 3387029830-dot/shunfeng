# Gate 3｜三种概念方向板任务书

- 项目：顺丰同城单张实体印刷广告
- 业务情境：D｜泛同城即时配送
- 授权状态：用户已明确批准本轮 Gate 3，方向固定为 B / C / C05
- 最终交付：仍然只有一张海报；本 Gate 的三张方向板只是选型研究，不是最终海报或系列海报
- 当前禁止：高保真成稿、最终海报、正式印刷输出、未经批准的图像生成、进入 Gate 4/5

## 1. 本轮唯一任务

制作三张**低保真、同尺寸、可公平比较**的完整海报构图方向板：

1. **G3-B｜一座城市装进一个包裹**（来自 Gate 2 C03，主推验证方向）
2. **G3-C｜折叠城市**（来自 Gate 2 C02，空间/纸艺方向）
3. **G3-C05｜包裹成为城市连接器**（来自 Gate 2 C05，备选对照方向）

不要制作 Gate 2 的 C01「交付的那一秒」。不要把旧 Gate2 A/B/C 字母直接沿用而造成命名混淆。这里的 G3-B、G3-C、G3-C05 是本次用户批准的方向名。

## 2. 三个方向必须真正不同

### G3-B｜一座城市装进一个包裹
- 机制：尺度反差 + 包装结构转化 + 克制的微缩城市。
- 主视觉事件：包裹打开/展开后，内部结构成为一座简化的城市；必须有一个明确的内外连接或交付节点，不能只是「箱子里摆了很多楼」。
- 关键风险：像房地产/城市规划模型、物流覆盖范围广告或微缩模型展示；细节过多会拥挤。
- 必须验证：在极简剪影下仍能读出「包裹与城市形成一个整体」。

### G3-C｜折叠城市
- 机制：空间折叠 + 单一纸艺雕塑/折面结构。
- 主视觉事件：原本分开的城市空间因一个清晰的折叠动作在折痕处相遇；交付物件是折点的语义落点。
- 关键风险：与 FedEx Neighbours 的空间压缩表达相邻。
- 禁止：地图墙、窗户对窗户、两栋楼伸手递物、照搬 FedEx Neighbours 的交接结构或构图。
- 必须先完成针对性近似案例检索并在报告中记录查询、查看结果和差异化判断。若不能证明独立性，不得把 C 方向包装成原创已成立；标注高风险并建议回退/调整，但本轮仍可用低保真抽象结构展示其问题。

### G3-C05｜包裹成为城市连接器
- 机制：一个包裹作为结构性连接件，扣合两个原本分离的空间模块。
- 主视觉事件：包裹插入/扣合两端模块，令其形成完整空间；包裹必须是连接关系的关键部件，不可退化为旁边的普通箱子。
- 关键风险：像拼图、积木或泛科技连接广告；隐喻过抽象。
- 必须验证：不读标题仍能看到「包裹正在连接两端」，而非抽象模块拼接。

## 3. 品牌元素嵌入规则（强制）

品牌元素必须进入创意结构，不能在最后作为装饰贴上去。每张方向板都要说明品牌如何成为主视觉关系的一部分：

- **业务层**：画面明确表达同城两端、即时交付/连接的关系，不要变成普通电商包裹、跨境物流或地产广告。
- **物件层**：可研究包装结构、封装/封签、交付标签、品牌配送承载物等，但不能臆造官方包装样式、面单、制服或车辆。
- **品牌识别层**：优先从已核实的官方资产中选择可用元素。当前官方 Logo/VI/品牌色/字体资产若仍未取得可靠来源，必须标记为「待核验」，不得凭印象把红黑白组合宣称为官方规范。
- **文字层**：可用「顺丰同城」作为品牌文字占位；不得编造官方 Slogan、配送时效数字、覆盖范围、价格优惠或服务承诺。自主创作广告语只能明确标注为概念文案，不可冒充官方口号。
- **结构层**：至少一个品牌相关物件或标识应与城市/包裹/折叠/连接发生物理或构图关系，而不是只放在角落。
- 每张板都提供「品牌融入说明」和「官方事实/资产待核验清单」。

## 4. 每张方向板交付内容

1. 一张同尺寸低保真完整构图（建议统一比例，不锁最终印刷尺寸）。
2. 核心创意句、目标理解路径（第一眼/第二眼）。
3. 主体结构图或物件关系图。
4. 标题、品牌名、辅助信息的占位与层级，不定稿广告语。
5. 品牌嵌入位置、方式、理由。
6. 视觉语言建议（摄影/纸艺/拼贴/矢量仅作候选，不在本轮锁定风格）。
7. 优势、弱点、误读风险、执行难度。
8. 纯黑剪影、灰阶、缩略图三种检查。
9. 一份三方向比较表与推荐顺序。
10. 可编辑源文件（优先 SVG）及预览；不得只有不可编辑的位图。

## 5. 统一比较条件

- 三张板使用完全相同的临时画幅比例、画布尺寸、信息层级框架和预览缩放。
- 不锁最终 A 系列尺寸；实体印刷规格在后续阶段确认。
- 三个方向都只能有一个主视觉事件。
- 辅助元素只保留读懂创意必需的最少数量。
- 同时检查去掉标题、去掉 Logo/品牌名后的主体是否成立；品牌名仍应在板上有明确占位。
- 不要通过更复杂的渲染让某一方向获得不公平优势；以结构清晰度和创意成立程度为比较重点。

## 6. 本轮严禁事项

- 不做最终海报、不做高保真细节、不做最终色彩系统。
- 不做人物角色设计，不恢复旧女性、沙发、客厅或人体时钟。
- 不直接下载/拼贴研究参考图，不临摹具体作品。
- 不生成正式广告图像；不调用生成式图片模型。
- 不制作三张最终系列海报；三张板只供选一个方向。
- 不自行选择最终方向；不进入 Gate 4/5。
- 不将桌面评分伪装成用户测试。

## 7. 验收与停止

- 三个方向视觉机制确实不同。
- G3-B 有明确的包裹—城市整体结构；G3-C 是独立折面雕塑而非地图/窗户交接；G3-C05 的包裹确实承担连接件功能。
- 顺丰同城品牌关联融入结构且不靠巨大 Logo。
- 官方资产/品牌事实均有来源或清楚标为待核验。
- 三张板同尺度、低保真、可编辑、缩略可读。
- 输出比较报告、源文件和预览，记录技术验证与艺术判断两类结果。
- 完成后停止，等待 ChatGPT 与用户评审。不得自动进入 Gate 4 或 Gate 5。

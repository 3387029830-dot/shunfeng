## 1. 任务成功的定义

在保持同一 700×990 研究画幅、正侧机位、固定腰胯中心和共享客厅的前提下，完成 **P1 心动 → P2 下单 → P3 享用** 的三张灰阶粗轮廓试样，使：
- 人能看出是**同一个成年女性**，动作情绪不同且自然；
- 双腿在剪影层面构成一条易辨的“时针”主轴，而不是原稿膝部 41°–43° 的断折；
- 上半身逐渐抬起形成动态“分针”方向，头、头发、胳膊不构成杂乱第三针；
- 身体确实被沙发承托，同一个固定场景能容纳三种姿势；
- 有温暖、圆润、克制的居家氛围和真实的喜悦/食欲表达，同时**人体时钟仍是第一视觉**；
- SVG 可编辑、能重复构建、可逐张独立修改，实际导出与记录测试可追溯。

**技术通过 ≠ 艺术通过**。即使程序全部 PASS，若纯剪影像普通坐卧动作、女性人物不可信、表情缺乏情绪、沙发承托失败，仍需明确 NO-GO。

## 2. 先做结构：两套腿轴候选

旧参数 `leg_angles.near = [-7,34]`、`far = [-9,34]`，导致 41°/43° 的膝关节转折。本轮至少做以下两组**有体块、有双腿、有袜尖**的候选，和旧版本同尺度并排：
- **L0 连贯轴**：大腿/小腿偏转差约 0°–10°，以连续、近似共线的视觉主方向为目标；
- **L1 轻自然弯曲**：差约 10°–15° 或经过理由说明的局部柔和弯曲，比较其人体自然性与可读性。
以上是首测范围，不是以数字取代艺术判断；如果自然接触要求超出范围，可提供 L2 备选并说明代价。

必须检查：固定 pelvis `(364,585)`；两腿基本平行、前后有轻微投影错开、不成两根互相冲突的钟针；从胯→膝→踝→袜尖形成明显一致的视觉方向；坐垫和靠背承重合理，脚尖不能无支撑地刺出家具。三张的腿部总方向相对稳定，允许**小幅必要的关节/脚部姿态补偿**，但要记录变动和为何仍能被读成同一时针。P3 不必强行变成双脚落地的普通坐姿。

特别测试“时针/分针”的视觉长度冲突：原头顶距胯约 199–209 单位，袜尖约 239。不能靠拉长脖子、躯干、手臂或缩短腿骗取长短；可研究衣形、局部遮挡、主轴终止点和刻度辅助。举出并排对照，坦率说明剩余限制。

**验收观测**：有轴线调试版与完全无骨架/无钟面提示的剪影版；只看后者仍具清晰主方向，且姿态像真实女性坐卧而不是折线模型。

## 3. 女性角色系统与表情研究

采用同一骨架长度/人物身份，重做头、颈、肩、胸腰、胯、双臂、双腿、手与服装的**整体轮廓**。不能仅添加长发或把脸改尖。成年女性自然比例、柔软宽松的居家上衣、长裤、袜子，不要性化/夸张胸腰臀。三张共享脸型、五官位置体系、发色灰度、服装切线、身材比例。

优先比较：
- H0：低扎发/低马尾，额前柔和刘海，头发收束、避免与躯干主轴冲突；
- H1：齐肩/中短发的简洁候选。若发型在某姿态创造出第三针，说明并淘汰，不因偏好强保留。

**每张必须有可以辨认的情绪与视线逻辑**，制作至少一组面部/头部局部对照（同角色）：
- P1：半躺、身体放松，带一点“突然想吃蛋糕”的期待与好奇；避免夸张惊讶、僵硬端坐；
- P2：上半身抬起，视线与手部集中到手机下单的位置，专注但愉快；手肘紧凑、腕部可信，不要用抬高手臂假装分针；
- P3：更直坐、关注已经得到的甜品，表情自然满足、令人感到有食欲；可有微笑、轻微欲尝或享受的嘴部动作，**不要直接复刻影视截图人物、鼓腮白奶油的强喜剧画面**。

手机、蛋糕、餐具仅可在这一轮用**极简灰阶体块或手势占位**做动作和视线验证；不得画正式手机 UI、精细蛋糕、配送包装或品牌。以不影响人体钟针与动作为条件，P1 的蛋糕想象气泡如会抢戏，先只用视线/表情表达，并在报告中说明后续叙事道具需求。

## 4. 背景与沙发：轻氛围而非家装成稿

借鉴奶油感居家照片的**构图、圆润度、柔软感和留白**，本阶段只做灰阶大形态研究；未来色彩方向记为米白/奶油白/暖灰，**禁止现在直接上正式彩色、材质精修或广告版式**。

至少：
1. 重新评估软包双人沙发 S0（圆角、适度宽座垫、可靠靠背、坐垫压陷）；
2. 在结构可能有收益时，提供 S1（含躺靠空间的简化延长沙发/贵妃位）候选，**三张仍使用同一套固定家具与投影关系**。如果 S1 不可行，提供几何证据并明确不采用，无需硬凑；
3. 放入轻量场景大形态占位：圆角低茶几、落地灯、小量抱枕/披毯。要有前后层、主体负形和呼吸感，家具不能盖住钟心或关键腿轴；
4. 检查 P1 肩背接触靠背、P2 坐骨支撑、P3 坐垫压陷/脚的承托，体块边缘不能悬空；
5. 不加入墙上实体钟、密集墙面搁板、摄影级纺织纹理、繁杂地毯花纹。背景对主体提供**明度分离**，不是灰度全挤在一起。

先完成无背景的人体剪影，再加共享沙发，最后加少量家居形状。场景方案的主评价标准是“舒服、统一、利于读钟”，不是装饰数量。

## 5. 钟面辅助：区别两个“A”

- **用户的方向 A = 抽象的人体时钟**，允许必要的辅助设计，不要求模拟真正走时。
- **旧图形方案 A = 完全没有钟面辅助**，作为零辅助对照保留。
- 旧图形方案 B（局部开放弧+少量刻度）和 C（四刻度）仍要比较，允许轻微减淡/挪位，**不画完整大钟**。

新人物/新沙发完成后，至少提供零辅助 A、优化 B、克制 C 的相同 P1/P2/P3 **3×3 对照**，并专门放大 P1 弧线与沙发靠背的切线问题、P2/P3 刻度和人体方向对应、C 的脚侧刻度被袜尖吞没问题。原报告主观认为 B 最好，但不能把它当作已证实的最终结果。主体优先、钟针负形与舒适度优先。

## 6. 建议实施顺序（不要跳步）

**Step 1：参数/结构试验。** 从旧 rig 派生，不修改旧 `source/stage1/generated`；输出 L0/L1 腿轴、三姿态骨架和无背景剪影。明确每套失败点。

**Step 2：女性体块与头部。** 共享角色几何与发型规范，完成 H0/H1 小对照；在一致比例上做 P1/P2/P3 动作与表情初稿。首先检验人物身份一致，再看美感。

**Step 3：场景包裹测试。** 将相同沙发及轻量家居大形态嵌入三张，检查接触与留白；如有必要比较 S0/S1。不要为了让某一张好看而偷偷移动其他画板的钟心/家具。

**Step 4：轻钟面辅助。** 在完全相同的新人体轮廓上测试 A/B/C，生成 3×3 版。不要用辅助图形救一幅本身彻底不成立的剪影。

**Step 5：技术回归与报告。** Inkscape 渲染、参数表、SHA256、局部更新、完整重建一致性，记录不能复现/缺环境的原因；然后停下交艺术审查。

若 Step 1 和 Step 2 出现不可调和的严重冲突，应明确 NO-GO，保留真实失败对照，不必为了“完成”强行推进成貌似精美的场景。

## 9. 验收与测试（必须区分）

**技术必检**：
- 画布统一（研究尺寸 700×990）、固定腰胯 `(364,585)`，场景源一致；必要调整画幅/腰胯须另请批准；
- 人物段长/比例/服装与角色 ID 统一，腿轴方向有可量化记录；
- 输出为可编辑 SVG 对象、无嵌入位图、对象 ID 不冲突；
- P2 定向修改不影响 P1/P3，修改共享场景更新全部三张且不篡改人物；
- 完整重复生成和相同环境重复导出比较；实际执行测试的命令、版本、输入、exit、哈希与结果；
- 不覆盖原 Stage 1 固定基线任何文件。记录新/旧 SVG 的 diff，说明是否做过系统外手工修形。

**艺术必审**（不要伪造机器 PASS）：
1. 第一眼优先感到人体时钟而非普通坐卧、茶几或钟面；
2. 下肢方向连续、真人膝踝自然，沙发上有真实重心/接触；
3. 是同一位自然成年女性，表情不僵硬、情绪有递进；
4. 暖居家氛围舒服、有特色但不杂乱，人体可辨；
5. P3 的食欲和满足清晰，但不过度滑稽；三张在同一世界；
6. 辅助 B/C 提升识别，却不成为单独的墙钟。

建议找 **2–3 位不了解项目的人** 随机看无标签小图，各先看约 2 秒，先记录“第一眼想到什么”，再问读钟和表情感受；由用户/评审实际实施，**未进行即写 NOT TESTED，不能自行宣称通过**。若盲测不便进行，可提交供 ChatGPT/用户查看的图并将外部反馈列为待办，不编造成绩。

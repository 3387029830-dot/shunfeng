## 参考 1：奶油系温暖客厅

画面：米白色墙面、浅奶油色圆角沙发、毛绒/编织抱枕、厚软织物覆盖坐垫和部分地面，浅色圆角茶几摆放少量生活物件。高处是较大的浅色纸艺吊灯；墙面有小型时钟和轻巧的悬挂搁板；右侧有质感柔和的落地灯和帘布。整体近似同色系，但靠体积、软硬材质变化营造层次。照片为居家摄影参考，**不是正式广告画法模板**。

可转译成原创二维图形的重点：
- **形**：宽大软包沙发、饱满坐垫/靠垫、圆角茶几、垂直的简洁灯具；家具让姿态有真实受力面
- **空间**：墙面足够干净，上部可形成稳定的呼吸空间，沙发围绕腰胯钟心承托人物
- **氛围**：舒适、柔和、温暖、有人住过的轻生活感，不是精装修效果图
- **灰阶测试方式**：只把奶油白、米白、暖灰的相对明度和软边体块转译成 3–5 档灰阶；可少量曲线代表软织物，不画精细绒毛纹理
- **减法**：去掉实物墙钟或至少不画可识别的钟盘，避免与人体时钟抢主角；搁板、烛台、地毯、装饰灯与茶具不得层层叠加使场景拥挤；茶几不能遮住骨盆与腿部主轴

## 参考 2：女性与草莓奶油蛋糕的互动

画面：两张上下连续的影视截图，近景侧向面部，一位深色头发、额前刘海、头发收束的成年女性手捧白色奶油草莓蛋糕，低头专注，眼睛集中在甜品，口边有明显奶油，表达很想吃/正在享用。背景是相对繁杂的厨房空间。用户偏好的是这张图的**食欲感、表情真实程度、人物和蛋糕之间的互动**，并非要求影视截图复刻。

可转译成原创二维广告插画的重点：
- **眼神**：头部略朝向蛋糕、目光与食物有清晰关联；不空洞地直视观众
- **表情**：嘴角、脸颊、眉眼的细微变化使 P3 看起来“真的开心吃到了”；P1/P2 也以表情递进联系这种期待
- **动作**：手腕/手指有可信的托持或餐具动作，动作安排服从人体时钟剪影，不将手臂变成第三根指针
- **角色**：参考低扎发/刘海可能适合，但必须原创女性脸型、比例与服装，不能照着真人临摹识别性特征
- **减法**：不复制影视角色、衣着花纹、厨房背景、蛋糕具体样式、口边夸张奶油或图像水印/界面。Stage 1.1 只使用灰阶蛋糕占位、动作和脸部草图验证情绪

## 两个参考与核心创意的冲突处理顺序

1. 人体时钟仍是远看第一视觉：头—背形成动态指针，腰胯为钟心，下肢为连续稳定指针；
2. 成年女性必须自然地躺/起/坐，脸部表情清晰，但细节强度不损害整体剪影；
3. 沙发与灯、茶几营造安全舒适的家，避免喧宾夺主；
4. 蛋糕/手机作为简洁叙事线索，品牌正式素材待后续阶段；
5. 研究阶段坚持灰阶；色彩偏好先进入意向，不替代 Stage 4 正式画风审批。

建议并排展示**“只有人物”**、**“人物+沙发”**、**“人物+轻场景”**三层状态，统一大小与坐标，以客观说明增加背景是否改善舒适感、是否削弱时钟的识别。

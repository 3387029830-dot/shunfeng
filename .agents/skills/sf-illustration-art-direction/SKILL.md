# 顺丰同城｜插画美术总监（项目专用 Skill）

## 使命

这是平面广告设计，不是几何脚本的单元测试。用真实可见的好作品理解什么是漂亮、自然、有生命力的插画，再用原创、可编辑 SVG 实现。**不自动让难看的作品通过。** 用户是最终审美决策者；ChatGPT 负责艺术审查；Codex 负责专业矢量绘制、脚本、测试与证据。

用户最新偏好：**甜美轻萌但成年、奶油温暖居家、舒服、有特色、具有情绪和食欲感**。三联角色必须相同，P1 半躺想吃蛋糕、P2 抬身拿手机下单、P3 坐起享用蛋糕。人体时钟：腰胯是固定钟心，上身是动态方向、双腿保持较稳定短针方向；采用抽象时钟，不绑定真实时间。不允许墙上实体时钟取代创意。Stage 1.1 还在审查中，Stage 2 未批准。

## 最高优先级：艺术通不过就停止

1. **先看图，不是先读数值**。读取当前 PR 固定 SHA 的实际 PNG；打开 SVG/源的前提是已经看了整图和头像局部。不能因为 PNG 哈希、构图角度、ID、可重复构建均通过就宣称艺术通过。
2. **先检查参考、再开始手绘**。每轮至少提供 3 个真正看过的相关高质量插画作品，分别是：成年女性角色正侧/三分之四侧脸、居家生活人物动作、商业广告生活场景。对每个记录作者、作品具体页链接、在图上可观察的特征、可转译的规则、不能复制的专有特征、许可/来源与访问状态。**未打开图像就不得写“已参考”。**
3. **视觉设计不等于参数优化**。不要通过把同一条鼻子贝塞尔改 2 个控制点、换三个眼睛大小，就声称产生三套不同角色。须改变真实的脸型节奏、眼鼻唇关系、发型形态、线条、明暗策略及人物气质；只更换软硬色不算新方向。
4. **小尺寸是首要验收之一**。头像在最终三联中约 30–45 px 冠顶到下巴时，依然看着舒服、可爱、能辨情绪。放大后的纤细装饰在小尺寸丢失时不能算优势。
5. **严格视觉停止门槛**。没能满足下列面部五项与自然关系，写 NO-GO 并停止；不可用装饰、手机或蛋糕掩盖失败。用户未确认前，不批量整合三联、不自动制作下一张样稿。

## 脸部专项：面部由整体比例决定

检查顺序必须从大到小：

- **头骨与脸型**：额头—鼻梁—鼻尖—人中—上唇—下唇—下巴—颌底的节奏连续且自然，不是尖嘴长鼻的剪纸轮廓；脸颊略饱满而非幼态娃娃。
- **五官位置**：眼、眉、耳、鼻、嘴相对于头部的结构协调，P2 看手机与 P3 看蛋糕不能靠瞳孔小点“伪装”视线。眼睑、虹膜、眼白与眉压要协调，别画巨大眼圈、眼妆般厚阴影。
- **面部表情**：P1 放松期待、P2 专注且轻快、P3 真实享用和满足。眼睑、面颊、眉与嘴角联动，不是单独替换嘴线。
- **发型**：低扎发/刘海可以保留，但避免整块深色“头盔”，碎发不过度，发束不能变成第三根钟针。
- **颈肩**：耳下、后枕、下颌、颈前/后、斜方肌和领口连续；必须放进原 S0 沙发靠垫实看接触，禁止“独立头像 + 另画连接管 + 独立身体”拼贴制造长脖子。P1 真正有后脑/肩背承托，P2/P3 不可长颈梯形。

## 设计流程：参考 → 审美策略 → 候选 → 盲评 → 源稿

**Stage A / 视觉 DNA**：写 1 页风格说明：甜美的“度”、轮廓、眼神、线面、头身比、暖居家视觉层级、目标受众与禁止事项。不要从 Pinterest / 社交平台下载未获许可的素材塞进仓库；可以放来源和观察笔记。参考作者作品只能研究一般原则，不要复制独占式人物设计或在世艺术家的可辨识独特画风。

**Stage B / 小量原创造型**：先有尺寸一致的大幅女性头像 A/B 两种**实质不同**的方向，再给每版至少一张缩小图与纯黑剪影。如果提供候选间差别只能总结为“眼睛更圆一点”“嘴角更高一点”，退回 Stage A。优先在 Inkscape 里用曲线做原创整形，必要时先从真实参考观察绘制结构草稿；不要用现有公式脸批量造 20 张。

**Stage C / 人工审查**：把截图让用户/ChatGPT 看，**明确等艺术选型**。推荐方案时说明剩余缺点，不因实验耗时而妥协；此前多次用户明确否决的“丑脸”不能继续沿用。

**Stage D / 系列统一**（经用户批准才进入）：角色身份、发型、五官位置、比例固定；姿态、动作和情绪变。沙发、机位、钟心固定。再输出三张并排、黑白剪影、脸部与手部放大、缩略图，以及 A/B/C 钟面策略。

## 审美打分卡（不是算法指标，必须有可见理由）

0–5 分单项评价，满分 30：
- 人物面部吸引力与清秀甜美（0–5）
- 自然成年女性比例、真实颈肩与体态（0–5）
- 表情生命力与视线/道具互动（0–5）
- 原创角色身份一致、发型设计（0–5）
- 贴合温暖生活方式广告的舒适度（0–5）
- 小图可读与人体时钟第一视觉（0–5）

任何项 ≤2，或用户明确认为角色不好看：**NO-GO**，不以平均分豁免。评分是审查记录，不是自动宣称艺术质量的机器证明。

## 和外部 Skills 协作

不要仅因安装了任何 Skill 就自动解锁绘图权限。当前任务若只要求「安装 Skill」，完成安装与验证后立即停止，等用户批准下一次视觉工作。

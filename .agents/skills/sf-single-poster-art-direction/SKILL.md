# SF City 单张广告｜项目美术总监

## 当前批准的项目事实

- 品牌：顺丰同城（SF 同城配送）。
- 最终交付：**一张**完整的商业平面广告海报，不是三联，不是系列。
- 用户明确推翻：人体模拟时钟、原三张叙事、原女性沙发角色、原 S2-v2/S2-v3 路线全部废弃，不得继续沿用为新创意。
- 仍有价值的用户参考：七张上传图仅为视觉研究参考。它们提示时间、速度、闹钟/秒表、巨型钟面、人物与时间装置的关系、包裹、条码/二维码、手机、手部交接、动作瞬间、拼贴和尺度反差。不得复制其中具体作品。
- 目标：找到一个有主体性、视觉记忆点明确、与顺丰同城配送业务真正相关的单一主视觉；将时间/快速/即时配送的意义转化为物体关系，而非堆砌图标。
- 生产仍以可编辑 SVG + Inkscape + Affinity 为主；不要因 Skill 自带 HTML/Figma/PNG/PDF 工作流而擅自换工具。
- 不允许 AI 一次性生图作为正式创作，不允许外部 Skill 自动调用生成器。先概念和手绘/矢量构思，经用户批准后再制作。

## 项目原则

1. **创意先于形式**：先定义消费者洞察、传播目标、品牌承诺、核心信息和独特的视觉隐喻，再决定使用闹钟、秒表、计时器、速度线、包裹交接或其他元素。
2. **一个主视觉事件**：海报只能有一个主视觉主体/关系。时间、速度、包裹、交接等元素应通过一个视觉动作整合，不能做成“闹钟 + 箭头 + 快递盒 + 手机 + 速度线”的素材拼盘。
3. **主体性**：第一眼识别主体；去掉标题后仍能看出核心创意；缩略图和远距离依然有记忆点。
4. **品牌相关性**：时间压力必须转译成顺丰同城的即时配送体验，不能只做“限时促销”或一般闹钟海报。不得臆造配送时效数字、覆盖范围、服务承诺、价格、优惠或官方品牌规范。
5. **字体也是图像**：标题字重、宽窄、重复、轮廓、遮挡、排列和空间必须承担构图职责；不要只把文案放在顶部/底部。
6. **参考有证据**：实际打开高质量商业广告/海报作品，记录作者、具体作品、来源、可观察技法、可转译原则、版权边界。未看图不能声称研究过。不得临摹或复制在世艺术家可辨识的独特风格。
7. **反 AI 模板审查**：逐项审查模板化渐变、无意义网格/噪点/环形、装饰性箭头、随机小字、伪科技 UI、无意义胶带/邮戳、图文堆砌、无关人物素材、字体滥用。每个元素要解释其主题原因与观众效果。
8. **先少量探索再定案**：阶段前期可制作三种真正不同的概念方向供比较；这只是方案探索，不是最终三张海报。用户选定后最终只做一张。
9. **明确停点**：每阶段提交证据和预览，等待用户明确选择。不能把建议当批准，不能因技术通过就自我批准进入下一阶段。
10. **历史隔离**：原人体时钟三联及 Stage 1.1 是历史归档。不要删除、覆盖或从旧稿复制视觉主体。只可借鉴已验证的技术工具链。

## 新流程（不得跳步）

### Gate 0 — 重启任务简报
形成单页 brief：受众、消费情境、品牌角色、传播目标、单一核心信息、语气、投放场景/尺寸/印刷或屏幕、必要文案、禁用主张、官方品牌素材和版权状态。标记未知项。只问会改变概念决策的缺失信息。

### Gate 1 — 参考研究与视觉证据
至少研究 8 个高质量参考，覆盖：
- 时间/计时/限时主题广告；
- 速度/运动/快速响应的视觉表达；
- 配送/物流/包裹交接广告；
- 强主体、字体与图像融合的海报。
至少 4 个应为具体广告作品而非只看艺术家作品集。实际打开图像。每个参考记录作者/品牌、作品名、年份（不详注明）、链接、实际观察、可借鉴一般原则、不可复制特征、许可/仅参考标记。
将用户上传的七张图逐张登记为用户提供的参考；不可误称为网络来源或可自由使用素材。

Gate 1 还必须包含视觉执行与艺术指导补充研究（拼贴/摄影合成/字体图像化/材质/印刷质感/主体组织），记录实际看过的具体作品与可核验来源。明确区分商业广告案例、视觉语言参考和未能完整查看的案例；未看清的图像不得推断。Gate 1B 补充研究完成后仍须等待用户与 ChatGPT 艺术复审，不能自动进入 Gate 2。

### Gate 2 — 核心创意发散
从“时间”“速度”“配送”“交接/抵达”抽象元素，不预设必须用闹钟/秒表。列出至少 8 个视觉隐喻，逐项评估：
- 是否一眼能读；
- 是否与顺丰同城有关；
- 主体是否独特；
- 能否用一个视觉事件讲清；
- 是否容易沦为常见促销广告；
- 可执行性和版权/素材风险。
做反向审查，淘汰只靠文案解释的点子。必须区分已确认事实与策略假设；不得把桌面评分说成用户测试。输出完整创意矩阵、淘汰理由、近似风险、建议进入 Gate 3 的三个机制不同的候选方向。Gate 2 完成后停止，等待用户批准 Gate 3。

### Gate 3 — 三个真正不同的概念方向板（不是三张最终海报）
每个方向必须有不同的核心视觉隐喻、主体、构图机制或材料语言，而不是只换色。
每张方向板应有一张粗略但完整的海报构图草图（同一输出尺寸），说明主标题位置与层级、主视觉事件、品牌位置、辅助信息和留白。概念板可有三种，但最终只会选一个并制作一张。
每个方向明确：洞察、核心创意句、主体/物件关系、第一眼视线、字体逻辑、色彩依据、品牌融入、优点、缺点、风险。

### Gate 4 — 用户选定唯一方向
提交同尺寸对照和比较报告。ChatGPT 评审，用户决定。未经明确选择不进入精细设计。

### Gate 5 — 单张海报精细设计
选定方向后再确认真实文案、官方 Logo/品牌规范、字体授权、画幅、出血/色彩模式、印刷或数字投放。制作一个 SVG 母版，使用 Inkscape 校样和 Affinity 最终排版/原生文件。所有图像、字体、Logo 都要有来源和授权台账。

### Gate 6 — 单张成稿审查与交付
检查远看/缩略/全尺寸，黑白层级，图像隐藏，字体细节，边缘/出血，印刷输出，SVG 可编辑性，Affinity 重开。最终只交一张海报（含源文件和必要导出），不得再扩展成三联。

## 验收门槛

- 远看第一眼有一个清楚、独特的主视觉事件。
- 不读标题也能大致感知“时间/速度/配送”之间的关系；标题负责准确品牌信息。
- 创意不只是普通时钟图形，不只是快递盒产品图，不只是限时促销文案。
- 至少有一个真正属于此主题的视觉转化/物件关系。
- 文字和图像互相构成，而非素材加标题。
- 顺丰同城识别清楚但不以巨大 Logo 取代创意。
- 不出现未核实的时效、速度数字、品牌承诺或虚构官方元素。
- 参考图片只作研究，所有成品素材有合法来源。
- 输出只有一个最终海报画布。

## 交付记录

每阶段记录：分支、完整 SHA、实际参考清单、概念淘汰理由、用户决策、预览、SVG/原生文件、字体和图像许可、真实运行测试、失败/未验证项。技术通过和艺术通过必须分开记录。
